### Featured Engineering Projects

#### 🤖 [AI Structured Data Chatbot](https://github.com/DilkhushNapit/AI-Structured-Data-Chatbot)
> **FastAPI • Python • OpenAI API • Data Processing**
- Built an intelligent data querying chatbot capable of parsing structured datasets (JSON/CSV) and generating real-time summaries.
- Implemented FastAPI endpoint architecture with automated input validation and prompt engineering pipelines.

#### 🩺 [MyDoctor - Appointment Booking System](https://github.com/DilkhushNapit/MyDoctor-Appointment-System)
> **React • Node.js • Express • MongoDB • JWT**
- Full-stack healthcare booking portal featuring role-based authorization (Patients, Doctors, Admin).
- Designed secure JWT authentication workflows, booking slot management, and responsive patient UI using Tailwind CSS.

#### 📡 [Smart Garbage Bin (IoT + GPS + SMS Alert)](https://github.com/DilkhushNapit/IoT-Smart-Garbage-Bin)
> **ESP32 / ESP8266 • C++ • SIM800L GSM • NEO-6M GPS**
- IoT hardware prototype monitoring garbage fill level using ultrasonic telemetry and dispatching automated SMS alerts with real-time GPS location coordinates.
- Optimized micro-controller power management and sensor sampling frequencies for reliable field operation.

#### 📚 [Book Review Web Application](https://github.com/DilkhushNapit/Book-Review-Web-App)
> **React • Node.js • Express • MongoDB**
- Web platform for discovering, rating, and posting book reviews with dynamic genre filtering and user feedback loops.

#### 🖐️ [Virtual AI Hand Gesture Keyboard](https://github.com/DilkhushNapit/Virtual-AI-Gesture-Keyboard)
> **Python • OpenCV • MediaPipe**
- Computer vision system detecting hand landmarks via webcam to trigger virtual keyboard input events in real time.
